# Danielle C. Barcela — sanplawir

A personal portfolio featuring films, writing, editing, and creative work.

## Website
This repository is prepared for GitHub Pages. Publish from the `main` branch and the root `/` folder.

## Editing
- `index.html`: biography, experience, awards, and contact information.
- `app.js`: projects, work links, and interactive behavior.
- `style.css` and `portfolio-updates.css`: responsive layout, colors, and animation.
- `assets/`: portrait and owner-supplied project images.

No build step or backend is required. `.nojekyll` tells GitHub Pages to serve the static files directly.

The site includes motion controls, a light/dark theme, project filters, and optional Google Drive previews. Original work links retain their respective Google Drive and Facebook availability settings.
